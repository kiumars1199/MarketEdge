## Key components (props → behavior)
- **MarketTable** `{rows, columns, sort, onSort, grouped, onOpen, onWatch}`: virtualized; group header
  rows; sticky header; skeleton rows while loading; empty state with "Reset filters".
- **EdgeCell** `{edge, edgeLow, realistic?}`: colored number + thin confidence bar (edgeLow/edge);
  tooltip with both plus realistic edge for flags.
- **WinChanceCell** `{p, low}`: "79% (76–82)".
- **VerdictBadge** `{verdict, warning?}`: Worth it (green), Thin (amber), Not worth it (red), No book (grey);
  warning icon with text.
- **FilterPanel** `{state, facets, onChange, tier}`: sections from `04`; counts; locked sections with Pro badge.
- **PresetBar** `{builtins, presets, active, dirty}`: chips; overflow menu; save dialog.
- **MarketDrawer** `{marketId}`: fetches `/api/markets/[id]` + `/api/book`; sections from F-04.
- **CurveChart** `{curve, price, fairLine}`: Recharts line (segment win chance vs price) + diagonal + marker.
- **StakeTable** `{stakes, capacity}`: rows $25/$100/$500/$1000 + custom stake input (recomputes via `/api/book?stake=`).
- **FreshnessPill** `{scannedAt}`: relative time, color thresholds.
- **UpgradeGate** `{feature, children}`: renders children or a blurred preview with an upgrade CTA.

## States to design for every data view
Loading (skeleton), empty (explain why + reset), error (retry + status link), stale data (amber banner),
gated (blur + CTA), offline (toast). Numbers never show `NaN`/`null` — show `—` with tooltip "not available".

## Display language (casual bettors first)
The audience is people who already bet casually, not quants. Every number must make sense to
someone who has never heard "edge" or "spread".

### Primary numbers (shown on cards and rows)
| Show | How it's computed | Example |
|---|---|---|
| **Expected return** (headline) | `edge / (ask + fee)`, i.e. `best.roi_pct` | **+33%** |
| **Market says** vs **Won before** (two bars) | `ask` as % vs `win_prob` as % | 68% vs 92% |
| **$100 bet → expect +$X** | `roi_pct` × $100 | expect +$33 |
| **Bet {outcome} at {price}** | `outcome`, `ask` in ¢ (prices stay in ¢, that's what Polymarket shows) | Bet Yes at 68¢ |
| **Chance label** | from `win_prob`: ≥ 80% "Likely to hit", 55–80% "Leans your way", 40–55% "Coin flip", < 40% "Long shot" | Likely to hit |
| **Similar past bets returned** | `realistic_edge / (ask + fee)` (flags only) | +24% |
| **Closes in** | relative time | 19h |

Cents-per-share **edge**, mid, spread, fee, retention, model level and sample sizes live under a
collapsed **"Details for pros"** section in the drawer and as optional table columns. A user setting
"Show numbers as: Simple (default) | Pro (¢ edge)" swaps the headline for traders who want cents.

### Why return % and not cents
Edge in cents is profit per $1-payout share. It's exact, but a casual user can't compare a 5¢ edge on a
90¢ bet with a 5¢ edge on a 20¢ bet (the second is 4x better per dollar). Expected return % is the
same idea per dollar staked, so "+33%" and "$100 → +$33" read instantly. Caveat to design for: return %
is naturally highest on cheap long shots, which lose most of the time. So every card also shows the
chance label, the default sort is "Best expected return" **among bets with a 40%+ chance**, and
"Most likely to win" is one click away.

### Labels instead of "worth it"
Don't repeat a verdict word on every row (it reads as robotic). The execution check becomes a quiet
**price check** that only speaks up when something's wrong:
| Internal `verdict` | Card / row | Drawer |
|---|---|---|
| worth it | nothing extra (the card's existence says it) | "Price check ✓ fair fill" |
| thin | amber dot "Spread eats most of this" | explains with numbers |
| not worth it | hidden from Best bets; in All markets shows "Price too high right now" | explains |
| low capacity (< $100) | "Only ~$X available at this price" | stake table shows it |
| edge ≥ 15¢ warning | "Unusually high — check details" | warning text |
Never use: "worth it" as a badge, "pick", "lock", "guaranteed", "sure thing", "AI says".

### Words to use
Best bets (not "flags") · My list (not "watchlist") · My bets (not "journal") · Results (not "track record")
· Expected return · Won before / How often similar bets won · Market says · Price check · Alert me · Save.
Explain expected return once per page in a tooltip: "If you made this kind of bet many times, this is
the average profit per dollar, based on how similar past bets resolved. Any single bet can lose."
